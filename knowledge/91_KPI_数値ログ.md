## 6. 記録ルール

- 数字は事実だけを記録する。
- 解釈・仮説・改善案は `reviews/96_週次レビュー/` に書く。
- 月次の締めは月末、翌月1日に更新する。
- 週次レビューは日曜または月曜に行う。
- Xの内部数値は投稿ログから集計する。
- Substack / note / Web / LINEの数値は、取得元を備考に残す。
